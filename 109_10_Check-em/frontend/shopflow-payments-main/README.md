# ShopFlow Payments

We are a 3 member team of computer science freshers. We have all recently been placed in a bank. As a part of our 2 week software engineering training, we have been asked to make a payment gateway website including frontend, backend, integration and using GitHub. Below are the features that we plan on implementing. Our ideal customer proposed is a retail shop like H&M.

Features:

Create a payment
Track payment status
Search and filter
Idempotency
Error handling
2 - Factor authentication
Multi-currency
Multiple payment methods
Payment reversal if payment fails
Donate small amount to charity
Autopay
Handle routing static and dynamic between our customer (retailer) and the banks (of the retailer and their customers who would be using our payment gateway).

Create the frontend website wiht all these feature. have a sequential multipage layout the way a payment gateway works. It should look clean and modern and it should clearly display the steps that are happening, process errors properly, show that it is secure.
